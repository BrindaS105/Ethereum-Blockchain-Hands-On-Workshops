# Workshop 1: Introduction to Ethereum and Blockchain Technology

## Objective
To introduce classmates and juniors to blockchain technology, Ethereum architecture, and the fundamental concepts behind decentralized applications.

## Topics Covered

### 1. Introduction to Blockchain
Blockchain is a decentralized digital ledger that records transactions across a distributed network.

Key characteristics:
- Decentralization
- Transparency
- Security
- Distributed record keeping

### 2. Introduction to Ethereum
Ethereum is a decentralized blockchain platform that supports smart contracts and decentralized applications (dApps).

### 3. Key Components of Ethereum
- **Tokens:** Digital assets operating on a blockchain.
- **Smart Contracts:** Programs that execute according to predefined conditions.
- **Blockchain:** A distributed ledger containing records of transactions.
- **Peers:** Computers participating in the blockchain network.

### 4. Ethereum Virtual Machine (EVM)
The EVM is the execution environment responsible for running smart contracts on Ethereum.

### 5. Ethereum Clients
Ethereum clients are software applications that allow computers to interact with the Ethereum network.

Different node types:
- Full Nodes
- Light Nodes
- Archive Nodes

### 6. Introduction to Go Ethereum (Geth)
Geth is an Ethereum execution client written in Go. It provides tools for interacting with Ethereum and running execution-layer nodes.

## Learning Activities
- Explained blockchain architecture.
- Discussed the Ethereum ecosystem.
- Introduced smart contracts and tokens.
- Explained different Ethereum node types.
- Introduced Geth and its role in blockchain development.

## Expected Learning Outcomes
Participants gained an introductory understanding of blockchain architecture, Ethereum, smart contracts, clients, and decentralized applications.

## Conclusion
The session established the foundational knowledge required to understand Ethereum and prepared participants for the practical exploration of Geth, wallets, and transactions.
