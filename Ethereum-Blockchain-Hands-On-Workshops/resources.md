# Learning Resources

The following resources can help learners explore Ethereum and blockchain technology further.

## Official Documentation

### 1. Ethereum
https://ethereum.org/en/developers/docs/

Introduction to Ethereum architecture, smart contracts, accounts, transactions, and decentralized applications.

### 2. Go Ethereum (Geth)
https://geth.ethereum.org/docs

Official documentation for Geth installation, configuration, and development.

### 3. Solidity
https://docs.soliditylang.org/

Documentation for Solidity smart contract programming.

### 4. GitHub
https://docs.github.com/

Guidance for repository creation, version control, and project documentation.
