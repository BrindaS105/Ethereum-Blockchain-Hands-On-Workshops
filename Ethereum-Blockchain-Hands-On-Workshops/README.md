# Ethereum Blockchain – Hands-On Workshops

## Overview
This repository documents a hands-on learning initiative focused on Ethereum Blockchain Technology and Go Ethereum (Geth).

The initiative was designed to introduce classmates and juniors to blockchain fundamentals and provide practical exposure to Ethereum clients, nodes, wallets, and transactions.

## My Role
I took the initiative to organize and conduct knowledge-sharing sessions for classmates and juniors, explaining fundamental blockchain concepts and demonstrating the working principles of Go Ethereum (Geth).

My responsibilities included:
- Planning the workshop topics and learning flow.
- Preparing technical explanations and presentation materials.
- Introducing participants to Ethereum and blockchain fundamentals.
- Explaining Geth, Ethereum clients, nodes, wallets, and transactions.
- Demonstrating relevant commands and practical workflows.
- Encouraging participants to explore blockchain technology.

## Workshop Sessions

### Workshop 1: Introduction to Ethereum and Blockchain Technology
Topics covered:
- Introduction to blockchain technology.
- Ethereum architecture and ecosystem.
- Tokens and smart contracts.
- Ethereum Virtual Machine (EVM).
- Ethereum clients and node types.
- Introduction to Go Ethereum (Geth).

### Workshop 2: Hands-On with Go Ethereum (Geth)
Topics covered:
- Introduction to Geth and its functionalities.
- Basic Geth commands.
- Ethereum node configuration concepts.
- Ethereum wallet management concepts.
- Understanding transaction structures.
- Introduction to transaction commands and JavaScript console interaction.

## Technologies and Tools
- Ethereum Blockchain
- Go Ethereum (Geth)
- Windows PowerShell
- JavaScript Console
- Git and GitHub

## Learning Outcomes
Through these sessions, participants were introduced to:
- Blockchain architecture and decentralization.
- Ethereum clients and node management.
- Digital wallets and transaction concepts.
- Basic command-line interaction with Geth.
- Practical applications of blockchain technology.
