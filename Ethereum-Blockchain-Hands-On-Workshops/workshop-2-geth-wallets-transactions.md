# Workshop 2: Hands-On with Go Ethereum (Geth)

## Objective
To introduce participants to the practical concepts of Go Ethereum (Geth), including node configuration, wallet management, and transaction workflows.

## Topics Covered

### 1. Geth Platform
Explained the functionalities of Geth:
- Node management.
- Transaction validation.
- Smart contract execution.
- Blockchain interaction.

### 2. Basic Geth Commands
Introduced participants to command-line operations, including:
- Checking the Geth version.
- Understanding development mode.
- Exploring node configuration options.
- Understanding command-line interfaces.

### 3. Ethereum Nodes with Geth
Discussed the concepts involved in:
- Creating a data directory.
- Configuring an Ethereum node.
- Understanding node data storage.
- Running a local development environment.

### 4. Ethereum Wallets
Explained:
- Ethereum wallet concepts.
- Public and private keys.
- Wallet account creation concepts.
- Account listing and management.
- Importance of credential security.

### 5. Ethereum Transactions
Explained the main components of an Ethereum transaction:
- Sender address.
- Receiver address.
- Transaction value.
- Gas fee.
- Transaction data.
- Digital signature.

### 6. JavaScript Console Interaction
Introduced the use of the Geth JavaScript console to understand:
- Accessing account information.
- Understanding wallet balances.
- Exploring transaction information.
- Understanding transaction receipts.

### 7. Applications of Geth
Discussed applications in:
- Decentralized Finance (DeFi).
- Digital identity.
- Tokenization of real-world assets.
- Blockchain-based applications.
- Healthcare record management concepts.

## Practical Demonstration
The session used Windows PowerShell and Geth-related command examples from the accompanying academic presentation to explain blockchain interaction and wallet workflows.

## Learning Outcomes
Participants were introduced to:
- Geth command-line operations.
- Ethereum node configuration concepts.
- Wallet architecture.
- Transaction structure and lifecycle.
- Blockchain development environments.

## Security Considerations
All demonstrations should be restricted to local development or approved test environments.

Private keys, passwords, seed phrases, and account credentials must never be shared or uploaded to GitHub.

## Conclusion
The session connected theoretical blockchain concepts with practical Geth workflows and helped participants understand how Ethereum clients interact with wallets, nodes, and transactions.
